# Требникъ — Отчитка · читалка и озвучка

Аудиочиталка и озвучка двух последований из **«Требника Петра (Могилы), часть 3»**:

| № | Последование | Частей | Примерная длительность озвучки |
|---|--------------|:------:|-------------------------------|
| 01 | Восследование молебное **о избавлении недугующаго обуревания и насилия духов нечистых** («отчитка от демонов») | 32 | ≈ 3 ч 20 мин |
| 02 | Восследование молебное **против чародеяний и обаяний человеков и скотов** («от колдунов») | 10 | ≈ 45 мин |

Программа читает тексты и **синтезирует аудио локально**. На роль
**священника** и роль **хора** пользователь назначает любые голоса —
из **17 проверенных** в трёх движках:

- **Microsoft edge-tts** (онлайн, MP3): Дмитрий, Светлана, мультиязычные
  Эндрю/Брайан/Ава/Эмма, украинские Остап/Полина;
- **Silero** (офлайн, WAV, `pip install silero`): Ксения, xenia v5,
  Айдар, Евгений, Айдар v5;
- **Piper** (офлайн, WAV, `pip install piper-tts`): Дмитрий, Руслан,
  Денис, Ирина — экспериментальные.

По обычаю священник читает мужским голосом (Дмитрий по умолчанию),
но пользователь волен назначить любой голос на любую роль. Один файл
на часть + полный файл всего последования.

## Возможности

- **Два вида текста** — переключатель «Под озвучку ↔ Церковнославянскій»:
  - *адаптированный* — то, что произносится в аудио (нормализованная орфография,
    вставленные псалмы и евангелия);
  - *церковнославянский* — оригинал книги с титлами и ударениями, **без
    встроенных цитат**: на псалмы, евангелия и молитвы — золотые **ссылки**,
    открывающие текст в диалоге.
- **Имя вместо «Имярек»** — по умолчанию «Максим»; можно ввести любое имя,
  мужское или женское. Имя **склоняется автоматически** (в том числе
  характерные формы: «о рабе твоемъ, Максиме» / «о рабе твоей, Марии»),
  родовые формы согласуются с вариантами, которые даёт сама книга
  («(и҆лѝ ѡ҆ рабѣ̀ твое́й)…»).
- **Никакого «твёрдого знака»** — из текста для озвучки удалены все «ъ»
  (дореформенные концевые «духовъ», «вековъ» и пр.). Раньше синтезатор
  речи иногда *произносил букву* «твёрдый знак» — теперь это исключено.
- **Пауза/продолжение** — кнопка «Слушать» переключает:
  «Слушать → Пауза → Продолжить»; продолжение — с того же места.
- **Ударения в озвучке (голоса Microsoft)** — автоматически ставятся
  знаки: «Иису́се» (ударение на «у», как в церковном чтении) и «ра́бе»
  (без знака слышится «рабЭ»/«Рабэ», со знаком — правильное «рА-бе»).
  Относится только к тексту синтеза: на экране и в файлах текст
  канонический. Silero ударения расставляет сам.
- **Караоке** — при прослушивании подсвечивается читаемая строка, текст
  прокручивается сам.
- **Голоса ролей по выбору** — священник и хор: любой из 17 голосов
  на любую роль (см. таблицу ниже); голоса с дефектом «Ии» лечатся
  подменой «Ии→Йи» (только текст синтеза).
- **Настройки сохраняются** — имя, род, скорость, голоса, служба, выбранная часть.
- Тёмная тема, тёплое золотое акцентирование, крупный читабельный шрифт.

## Быстрый старт

Требуется **Python 3.10+** (Windows, macOS, Linux).

```bash
python -m pip install -r app/requirements.txt
python app/trebnik_player.pyw     # в Windows — двойной щелчок по файлу
```

Для **офлайн**-движков дополнительно (по желанию, любой из двух —
или оба). Важно: `python` — тот же интерпретатор, которым запускается
плеер (в Windows удобно писать полный путь к python.exe), поэтому
`python -m pip`, а не просто `pip`:

```bash
# Silero (Ксения, Айдар, Евгений и др.) — сначала компактный CPU-torch,
# иначе pip потянет гигабайтную сборку с CUDA:
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install silero

# Piper (экспериментальные голоса):
python -m pip install piper-tts
```

Интернет нужен только для синтеза через Microsoft edge-tts (готовые файлы
проигрываются офлайн); Silero и Piper работают полностью офлайн
(модели скачиваются один раз при первом синтезе).

Порядок работы: выберите часть в списке слева → кнопка **«Синтезировать
часть»** (или **«Всё последование»**) → **«Слушать»**. Аудио складывается в
`audio/<служба>/NN_название.mp3` (у офлайн-движков — `.wav`) и
переиспользуется; при смене имени, рода, скорости или голосов программа
подскажет пересинтезировать.

## Формат текста озвучки

```
--- ЧАСТЬ 09. ПРОКИМЕН. ЕВАНГЕЛИЕ ОТ МАРКА (строки книги 193-240) ---
[С] Иерей же заклинаяй крепко повелев держати беснаго…
[Д] Премудрость, прости, услышим сие: Евангелие. Мир всем.
```

- `[Д]` — голос «Дмитрий» (священник/заклинатель), `[С]` — «Светлана»
  (хор, предстоящие, рубрики).
- «(строки книги N–M)» — соответствие церковнославянскому оригиналу
  (номера строк его файла): так переключаются оба вида.
- Токены имени и рода подставляются при показе и синтезе:
  - `{ИМЯ}`, `{ИМЯ_Р}`, `{ИМЯ_Д}`, `{ИМЯ_П}` — имя в именительном,
    родительном, дательном, предложном/звательном падежах;
  - `{РАБ_П}`, `{РАБ_Г}`, `{РАБ_Д}`, `{РАБ_В}`, `{РАБ_БР_Г}`… — родовые
    обороты («рабе твоем/рабе твоей» и т.п.);
  - `{М=…|Ж=…}` — альтернатива по роду (в церковнославянском тексте
    восходит к вариантам самой книги «(и҆лѝ …)»).

### Голоса и роли: 17 проверенных голосов

Роли назначает пользователь: любой голос — на роль священника или хора,
любого пола. Единственное ограничение: **оба голоса должны быть из одного
движка** (MP3 у Microsoft и WAV у офлайн-движков склеить нельзя — плеер
предупредит и не даст начать синтез).

Проверка проводилась синтезом с ASR-распознаванием и анализом формант
(F1/F2 гласных) на фразах «Господи Иисусе Христе…», «Молитва о рабе
Твоем… диаволское действо» и на реальном фрагменте чина:

| Голос | Пол | Движок | «Иисусе» | «о рабе Твоем» | Примечание |
|---|:---:|---|:---:|:---:|---|
| Дмитрий | М | MS | ✗ → лечится | ✓ | по умолчанию — священник |
| Светлана | Ж | MS | ✗ → лечится | ✓ | по умолчанию — хор |
| Эндрю | М | MS | ✗ → лечится | ✗ «рабете» | мультиязычный |
| Брайан | М | MS | ✓ | ✗ «рабете» | мультиязычный |
| Ава | Ж | MS | ✓ | ✗ «рабете» | мультиязычная |
| Эмма | Ж | MS | ✗ → лечится | — | мультиязычная |
| Остап | М | MS-uk | ✓ | ✓ | украинское произношение (г, ы) |
| Полина | Ж | MS-uk | ✓ | ✓ | украинское произношение (г, ы) |
| **Ксения** | Ж | **Silero** | **✓** | **✓** | **лучший голос проверки** |
| xenia v5 | Ж | Silero | ✓ | почти | местами спотыкается |
| Айдар | М | Silero | ✗ → лечится | ✓ | офлайн-священник |
| Евгений | М | Silero | ✗ → лечится | — | — |
| Айдар v5 | М | Silero | ✗ → лечится | — | — |
| Дмитрий | М | Piper | ✗ → лечится | — | эксперим.: глотает слоги |
| Руслан | М | Piper | ✓* | — | эксперим.: глотает слоги |
| Денис | М | Piper | ✓* | — | эксперим.: глотает слоги |
| Ирина | Ж | Piper | ✓* | — | эксперим.: глотает слоги |

\* изолированное слово чисто, но во фразах Piper глотает слоги.

**«Лечение» дефекта «Ии»** — подмена «Ии→Йи» в начале слова, которая
запускается галочкой «Ии→Йи (лечить дефект)» и применяется только к
голосам с дефектом и только к тексту синтеза: на экране и в файлах
текста «Иисусе» всегда остаётся каноническим. Голосам без дефекта
(Ксения, Брайан и др.) подмена не нужна и не включается.

Для голосов Microsoft дополнительно и автоматически ставятся знаки
ударения (проверено синтезом + ASR, см. комментарий к `tts_clean`):
«Иису́се» — ударение на «у»; «ра́бе» — без знака фраза «молите Бога о
рабе своем» звучит с ударным концом («рабЭ», то самое «Рабэ»), со
знаком ударение правильно уходит на «рА». Вариант «рабье» проверен и
отвергнут: ASR слышит лишнее «й» («рабьйе»). При смене версии текстовых
правок (ревизия `TEXT_FIX_REV`) кэш аудио сам считается устаревшим —
достаточно нажать «Синтезировать».

Отдельные слова звучат «твёрдо» по вине самого текста книги: «диаволское»
в оригинале пишется без «ь» («діаволское») — так и читается.

Скорость чтения: работает для Microsoft (rate) и Piper (длина фонем);
Silero читает в естественном темпе.

Пакетный конвейер `tools/build_audio_script.py` пока остаётся на голосах
Microsoft с подменой «Ии→Йи»; выбор голосов — в плеере.

## Если что-то падает

Любая ошибка синтеза показывается в **специальном окне**, текст в котором
можно выделить и скопировать (Ctrl+C, правая кнопка → Копировать, кнопка
**«Скопировать всё»**). Тот же текст **автоматически дописывается в файл
`app/error_log.txt`** — можно прислать этот файл целиком: по трассировке
видно, на каком шаге всё упало. Частые причины на Windows:

- пакеты поставлены «другим» Python'ом — переустановите тем же
  интерпретатором (`python -m pip install …`);
- `torch` падает с «DLL load failed» — поставьте **Microsoft Visual C++
  Redistributable** (vc_redist.x64.exe) и перезапустите плеер;
- модель не качается — проверьте доступ к github.com / models.silero.ai
  (Silero) или huggingface.co (Piper: при недоступности HF автоматически
  пробуется зеркало hf-mirror.com);
- **«No audio was received» у онлайн-голосов Microsoft** — в октябре 2026
  Microsoft закрыл старый протокол Read Aloud
  (`speech.platform.bing.com`) и перевёл серверы на новый
  (`api.msedgeservices.com`). Плеер **переключается на новый протокол
  автоматически** при первом же сбое (версия от 26.10.2026 и новее);
  если ошибка всё же повторяется — обновите пакет
  (`python -m pip install -U edge-tts` — в будущих версиях новый
  протокол из коробки) или используйте офлайн-голоса (Silero/Piper),
  которым интернет для синтеза не нужен.

## Почему аудио не хранится в git

Полная озвучка — это ~170 МБ MP3, а один файл целиком — до 80 МБ.
GitHub жёстко запрещает файлы **больше 100 МБ** и предупреждает о файлах
больше 50 МБ; тяжелее становится и клонирование. Поэтому:

- `audio/` добавлена в `.gitignore` — аудио генерируется локально;
- при желании выложить готовые MP3 — прикрепите их к **GitHub Release**
  (лимит 2 ГБ на файл) или положите в облако, а ссылку дайте в README.

## Рекомендации по воспроизведению

Длительность и разбиение на части соответствуют церковной структуре
последования: вводное наставление, молитвы священника, псалмы, канон,
заклинательные молитвы, евангельские чтения, отпуст. Слушать можно как
целиком, так и по частям; караоке доступно в виде «Под озвучку».
