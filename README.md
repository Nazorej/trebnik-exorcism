# Требникъ — Отчитка · читалка и озвучка

Аудиочиталка и озвучка двух последований из **«Требника Петра (Могилы), часть 3»**:

| № | Последование | Частей | Примерная длительность озвучки |
|---|--------------|:------:|-------------------------------|
| 01 | Восследование молебное **о избавлении недугующаго обуревания и насилия духов нечистых** («отчитка от демонов») | 32 | ≈ 3 ч 20 мин |
| 02 | Восследование молебное **против чародеяний и обаяний человеков и скотов** («от колдунов») | 10 | ≈ 45 мин |

Программа читает тексты и **синтезирует аудио локально** (edge-tts, нейроголоса
Microsoft): священник и заклинатель — голос **«Дмитрий»**, хор, предстоящие и
пояснения — **«Светлана»**, скорость по умолчанию **0.8** (медленное, благоговейное
чтение). Один MP3-файл на часть + полный файл всего последования.

## Возможности

- **Два вида текста** — переключатель «Под озвучку ↔ Церковнославянскій»:
  - *адаптированный* — то, что произносится в аудио (нормализованная орфография,
    вставленные псалмы и евангелия);
  - *церковнославянский* — оригинал книги с титлами и ударениями, **без
    встроенных цитат**: на псалмы, евангелия и молитвы — золотые **ссылки**,
    открывающие текст в диалоге.
- **Имя вместо «Имярек»** — по умолчанию «Максим»; можно ввести любое имя,
  мужское или женское. Имя **склоняется автоматически** (в том числе
  характерные формы: «о рабе твоемъ, Максиме» / «о рабе твоей, Марии»),
  родовые формы согласуются с вариантами, которые даёт сама книга
  («(и҆лѝ ѡ҆ рабѣ̀ твое́й)…»).
- **Никакого «твёрдого знака»** — из текста для озвучки удалены все «ъ»
  (дореформенные концевые «духовъ», «вековъ» и пр.). Раньше синтезатор
  речи иногда *произносил букву* «твёрдый знак» — теперь это исключено.
- **Караоке** — при прослушивании подсвечивается читаемая строка, текст
  прокручивается сам.
- **Настройки сохраняются** — имя, род, скорость, служба, выбранная часть.
- Тёмная тема, тёплое золотое акцентирование, крупный читабельный шрифт.

## Быстрый старт

Требуется **Python 3.10+** (Windows, macOS, Linux).

```bash
pip install -r app/requirements.txt
python app/trebnik_player.pyw     # в Windows — двойной щелчок по файлу
```

Интернет нужен только для синтеза (edge-tts обращается к сервису Microsoft;
готовые файлы проигрываются офлайн).

Порядок работы: выберите часть в списке слева → кнопка **«Синтезировать
часть»** (или **«Всё последование»**) → **«Слушать»**. Аудио складывается в
`audio/<служба>/NN_название.mp3` и переиспользуется; при смене имени, рода
или скорости программа подскажет пересинтезировать.

## Формат текста озвучки

```
--- ЧАСТЬ 09. ПРОКИМЕН. ЕВАНГЕЛИЕ ОТ МАРКА (строки книги 193-240) ---
[С] Иерей же заклинаяй крепко повелев держати беснаго…
[Д] Премудрость, прости, услышим сие: Евангелие. Мир всем.
```

- `[Д]` — голос «Дмитрий» (священник/заклинатель), `[С]` — «Светлана»
  (хор, предстоящие, рубрики).
- «(строки книги N–M)» — соответствие церковнославянскому оригиналу
  (номера строк его файла): так переключаются оба вида.
- Токены имени и рода подставляются при показе и синтезе:
  - `{ИМЯ}`, `{ИМЯ_Р}`, `{ИМЯ_Д}`, `{ИМЯ_П}` — имя в именительном,
    родительном, дательном, предложном/звательном падежах;
  - `{РАБ_П}`, `{РАБ_Г}`, `{РАБ_Д}`, `{РАБ_В}`, `{РАБ_БР_Г}`… — родовые
    обороты («рабе твоем/рабе твоей» и т.п.);
  - `{М=…|Ж=…}` — альтернатива по роду (в церковнославянском тексте
    восходит к вариантам самой книги «(и҆лѝ …)»).

### Фонетические корректировки синтеза

Нейроголоса Microsoft (edge-tts) имеют две особенности, которые программа
компенсирует автоматически в `tts_clean()` — только при отправке в синтез,
на экране текст не меняется:

- **ъ** (дореформенный) — движок пытается его «дочитать», портя соседние
  слоги («рабе своемъ» → «рабэ»): удаляется полностью;
- **«Ии» в начале слова** — «Иисусе» произносится как «Эсусе» (подтверждено
  акустически: форманта F2 первого гласного падает с ~2500 до ~1600 Гц):
  для синтеза заменяется на «Йисусе», что звучит как правильное «Йиисусе».

Отдельные слова звучат «твёрдо» по вине самого текста книги: «диаволское»
в оригинале пишется без «ь» («діаволское») — так и читается.

## Почему аудио не хранится в git

Полная озвучка — это ~170 МБ MP3, а один файл целиком — до 80 МБ.
GitHub жёстко запрещает файлы **больше 100 МБ** и предупреждает о файлах
больше 50 МБ; тяжелее становится и клонирование. Поэтому:

- `audio/` добавлена в `.gitignore` — аудио генерируется локально;
- при желании выложить готовые MP3 — прикрепите их к **GitHub Release**
  (лимит 2 ГБ на файл) или положите в облако, а ссылку дайте в README.

## Рекомендации по воспроизведению

Длительность и разбиение на части соответствуют церковной структуре
последования: вводное наставление, молитвы священника, псалмы, канон,
заклинательные молитвы, евангельские чтения, отпуст. Слушать можно как
целиком, так и по частям; караоке доступно в виде «Под озвучку».
